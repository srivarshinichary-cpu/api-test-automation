# API Test Automation Framework

An API test automation project built using Python, Pytest, and Requests
to test REST APIs with automated validation and HTML reporting.

## Technologies Used

- Python
- Pytest
- Requests
- REST API Testing
- pytest-html
- GitHub Actions
- Git and GitHub

## Test Coverage

- GET: Retrieve users
- POST: Create a user
- PUT: Update a user
- DELETE: Delete a user
- Negative Testing: Validate responses for invalid user IDs
- Response status code validation
- Response body validation
- Response time validation
- Request timeouts
